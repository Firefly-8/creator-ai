### ② PayPal 后台注册（开发者账号）

1. <https://developer.paypal.com/dashboard> —— 用普通 PayPal 账号登录
2. 右上角切 **Sandbox** → **Testing Tools → Sandbox Accounts**
3. 注册时自动有一对买家/卖家账号；**密码**在 `…` → View/Edit Account → Profile
4. **Apps & Credentials** → Default Application → 复制 **Client ID** 和 **Secret**

### ④ 正式商家账号（要收真钱时才做）

中国大陆用户注册 PayPal 商家账号：

| 账户类型 | 需要提供 |
|---|---|
| **企业账户**（推荐） | 企业所有者信息（须与营业执照法定代表人一致）+ 营业执照扫描件 + 法定代表人身份证明 |
| 个人卖家 | 个人经营者信息 + 身份证明（⚠️ 以营利为目的的销售应选企业账户） |

⚠️ **中国大陆用户的关键约束**：
- 身份验证必须用**居民身份证上的中文姓名**，**不许用拼音**；非中国公民用护照
- 选「企业账户」后会跳转到 **贝宝支付（北京）有限公司** 的注册流程
  （中国监管要求），主体信息要跟那个流程里的一致
- 激活账号时需提供**法定代表人身份证明正反面**
- 所有用户都要先认证银行账户或卡信息才能提现：
  - 银联卡 → 短信验证码，**即时**
  - 国际信用卡 → 扣 $1.95 生成 4 位码，2-3 个工作日后退回

## 四、提现成本 —— 这条会直接影响你的定价

| 提现方式 | 周期 | 手续费 |
|---|---|---|
| 电汇至中国大陆银行（美元） | 3-7 工作日 | **每笔 $35** ⚠️ |
| 提现至中国香港银行（港币） | 3-6 工作日 | ≥1000 港币**免费**；以下每笔 3.50 港币 |
| 提现至美国银行（美元） | 1 工作日 | **每笔 $35** ⚠️ |
| 支票（美元） | 4-6 周 | 每笔 $5 |

**这意味着什么**：
- 单张卡 $6.99，一次提现 $35 → **要卖约 5~6 张才够手续费** ❌
- 交易本身还抽成（约 3.5% + $0.30/笔）
- 提价后（2026-10-21）买断包 $59.99 / 20 张 = $3.00 一张，
  是摊薄手续费的**主力档**；月付 $19.99 每月自动回款，不用等凑够 35 块

**几个方向**（你得选一个）：
1. **攒够再提现**（比如满 $200 提一次，手续费摊薄到 17%）—— 资金会压在里面
2. **用香港银行账户提现**（满 1000 港币免费）—— 需要香港账户
3. **主用 Stripe / Paddle 等**（按笔收，无提现费），PayPal 只作为备用 ✅ **← 我倾向这个**
4. **提高客单价**（主推 $59.99 买断包，20 张摊薄手续费）✅ 已执行

另外 PayPal 对订阅有**争议/退款风险**：用户可以直接在 PayPal 发起争议，
金额会先从你的余额扣掉。所以客单价越高、争议绝对值越大。
