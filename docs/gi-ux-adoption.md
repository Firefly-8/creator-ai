# Greeting Island UX → Create Keepsakes 采用清单

> 基点：`origin/test` · 2026-11-23  
> 原则：学**节奏与便利性**，不抄 GI 品牌/模板资产；不编造未测高级/付费能力；闸门仍在**生成额度**与**去水印**，不照搬 GI「匿名全编辑、仅 Save 登录」。

| # | GI 便利点 | 决定 | 本产品实现 |
|---|---|---|---|
| 1 | 场景落地 + 预选带入 | **采用** | SEO/`?scenario=`/`?format=`/`?for=` 进入 `/cards` 后自动打开工作区并预填 |
| 2 | 明确开始入口 | **采用** | 首页/SEO CTA → `/cards…`；落地即开遮罩工作区（不再多点一次） |
| 3 | 模板库筛选/详情页 | **不采用** | 无模板库后端；用场合+画风浏览代替；不堆假模板墙 |
| 4 | 进入即创作（连续工作区） | **采用** | 同一遮罩：`params → generating → editor`；桌面宽面板、移动全屏 |
| 5 | 不落回营销页内嵌编辑 | **采用** | 出图后编辑器留在遮罩内，不 `closeForm` 滚到 hero 下方 |
| 6 | 即时预览 + 上下文编辑 | **采用（已有+加强）** | Canvas 实时预览；选中拖字；版式/主题即时改 |
| 7 | 富文本全套（字距/弯曲等） | **不采用** | 无排版引擎；保留版式预设 + 名称/留言/签名 |
| 8 | 主题 4 色一键换肤 | **采用（本地）** | 编辑器主题色预设，只改文字/蒙版色，**不**调 AI |
| 9 | 贴纸 / 照片蒙版裁剪 | **不采用** | 无贴纸资产与蒙版管线；参考图仍走 i2i 整图 |
| 10 | Undo / Redo | **采用（本地）** | 版式+文字快照栈；不含 AI 再生成 |
| 11 | 草稿自动保存 / 重开 | **采用（已有+加强）** | localStorage 草稿 + PUT meta；`?from=` 重开进编辑相 |
| 12 | 返回改参数不丢 | **采用** | 工作区内「Back to details」回参数相，保留名字/场合/候选 |
| 13 | Save 脏状态 / Next 交付收口 | **采用（P0 已有）** | Keep（自动存+Finish）与 Take（下载/分享/打印/PDF）分区 |
| 14 | 下载前选去水印 vs 带水印 | **采用（已有）** | 权限条 + `Download free (with mark)` / Remove watermark→定价 |
| 15 | 匿名改模板、登录才 Save | **不照搬** | AI 有成本 → 登录闸仍在**点生成**；匿名可填表+本地草稿 |
| 16 | GIF / RSVP / 实物印刷 | **不做** | GI 亦未完整实测；无后端 |
| 17 | `/image` 旧台 | **统一入口** | 默认导向 `/cards`；`?legacy=1` 保留旧高级台（路由兼容） |
| 18 | 移动端 / a11y | **采用** | 全屏工作区、`role=dialog`、Esc 关闭确认、焦点在面板 |

## 验收口径（用户可感知）

从首页点 CTA → 遮罩已开 → 填表 →（mock）生成进度在遮罩内 → 编辑/导出仍在遮罩 → 关闭可再开并恢复草稿。  
手机同链路可用。不要求真人 Firebase/付费 AI 才算完成（mock 区分报告）。
