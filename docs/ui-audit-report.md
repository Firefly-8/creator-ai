## 1. 竞品对比分析

### 1.1 Suno AI (suno.com)

| 维度 | 评分 | 特点 |
|------|------|------|
| 信息架构 | ⭐⭐⭐⭐⭐ | 左侧导航 + 社区 Feed + 创作页三栏式，层级极清晰 |
| 视觉设计 | ⭐⭐⭐⭐⭐ | 暗紫主题，卡片式作品展示，大量留白 |
| 交互设计 | ⭐⭐⭐⭐⭐ | "Create" 极简（仅风格+歌词），"Explore" 社区驱动 |

## 2. 当前项目 UI 审查

### 2.1 ✅ 优点

#### 视觉设计
- **配色系统成熟**：CSS 变量（tokens.css）统一管理色板，青紫色系（#8b7cff）符合 AI 工具品牌调性
- **暗色主题**：符合 AI 创作工具的品类认知（Suno/Leonardo 都是暗色）
- **字体选择合理**：Sora（标题）+ Manrope（正文），现代感与可读性兼顾
- **毛玻璃效果**：backdrop-filter 使用得当，提升质感

#### 组件架构
- **StudioWorkspace**：统一的工作台布局（左操作 + 右结果），复用性高
- **AuthModal**：登录注册弹窗 + Tab 切换，交互流畅
- **PresetMarquee**：跑马灯式预设展示，视觉吸引力强
- **Player Bar**：底部播放器固定，体验完整

#### 技术实现
- **响应式适配**：768px 断点，移动端侧边栏抽屉化
- **i18n 架构**：5 语言配置完整，strategy 合理
- **Nitro preset**：cloudflare-pages 适配正确

### 2.2 ❌ 不足

#### A. 首页 / Landing Page（严重）

| 问题 | 详情 | 竞品对比 |
|------|------|----------|
| **无品牌标识** | Hero 区无 Logo，仅文字标题 | Suno/Udio 都有醒目 Logo |
| **无作品展示** | 首页无用户生成内容预览 | Suno/Midjourney Gallery 驱动 |
| **无社交证明** | 无用户数/作品数/品牌背书 | 竞品均有"XXX creators"展示 |
| **CTA 单一** | 仅 "Start Creating Free" 一个主 CTA | 竞品通常有 "Try Free" + "See Examples" |
| **无实际内容预览** | Features 仅为文字卡片，无图/视频 | 竞品均有 Demo 视频或作品展示 |
| **Hero 文案泛化** | "Create AI Music & Images in Seconds" 无差异化 | 竞品文案更具体、更有画面感 |

#### B. 信息架构（中等）

| 问题 | 详情 |
|------|------|
| **导航分组不合理** | Music / Image 分组忽略了 Dashboard、Pricing 等入口 |
| **缺少返回首页入口** | 侧边栏 Logo 指向 /create 而非 / |
| **无搜索功能** | 库内作品增多后无法快速定位 |
| **Pricing 入口缺失** | 侧边栏无 Pricing 入口，仅首页有 |

#### C. 注册/登录流程（中等）

| 问题 | 详情 |
|------|------|
| **GitHub 登录显示但不可用** | 点击提示 "coming soon"，体验差 |
| **无登录后引导** | 新用户注册后直接跳 Dashboard，无新手引导 |
| **AuthModal 与独立页面并存** | /login 和 /signup 是独立页面，AuthModal 是弹窗，两套入口逻辑不一致 |

#### D. Dashboard（严重）

| 问题 | 详情 |
|------|------|
| **全假数据** | `stats.music: 0`, `plan: 'free'` 全为硬编码 |
| **无实际内容** | Recent Creations 永远为空 |
| **无使用量可视化** | 无数饼图/进度条显示剩余额度 |

#### E. 国际化（严重）

| 问题 | 详情 |
|------|------|
| **大量中文硬编码** | 创建页、图片页、库页的标题/提示/按钮全是中文 |
| **i18n 文件覆盖不足** | 仅 120 行/语言，远不能覆盖所有 UI 文案 |
| **无 RTL 支持** | 未来如需支持阿拉伯语需重构 |
| **仅 5 语言** | 缺西班牙语、葡萄牙语、意大利语、中文、印地语 |

#### F. 转化优化（中等）

| 问题 | 详情 |
|------|------|
| **无使用量提示** | 用户不知道自己还剩多少免费额度 |
| **无升级引导** | 免费用户无升级 CTA |
| **无邮件收集** | 未登录用户离开时无挽留机制 |
| **Pricing 无 FAQ** | 价格页缺少常见问题，转化阻力大 |

#### G. 移动端（轻微）

| 问题 | 详情 |
|------|------|
| **Player Bar 遮挡** | 92px 底部播放器在小屏遮挡内容 |
| **无底部导航** | 移动端无 Tab Bar，切换功能需展开侧边栏 |

## 4. 改进建议（按优先级排序）

### 🔴 P0 — 影响核心体验，必须立即修复

#### 4.1 首页大幅改造

**现状问题**：当前首页为纯文字 + 卡片，无法传达产品价值。

**建议方案**：
```
[Header: Logo + Nav + Language + Sign In/Get Started]
[Hero: Logo + 大字标题 + 副标题 + 主CTA + 次CTA]
[Showcase: 自动播放用户作品（音频波形+封面 或 图片画廊）]
[Features: 3列卡片（图标+标题+描述），配动态演示图]
[How it works: 3步流程图（Describe → Generate → Download）]
[Social proof: 用户数 + 作品数 + 品牌Logo墙]
[Pricing teaser: 3卡片预览 + "View All Plans" CTA]
[FAQ: 5-8个常见问题]
[Footer: 完整导航 + 社交链接 + 语言选择]
```

**关键改动**：
- Hero 区增加产品 Logo（已在生成中）
- 增加自动轮播的作品展示区（Showcase）
- 增加社交证明数据（"Join 50,000+ creators"）
- 增加实际 Demo 截图/GIF

#### 4.2 修复国际化硬编码

**现状**：创建页、图片页、库页大量中文文案（"还没有歌曲"、"歌词生成中"等）。

**建议**：
- 将所有 UI 文案提取到 `locales/en.json`
- 在 Vue 组件中使用 `t('key')` 替代硬编码中文
- 优先级：创建页 > 图片页 > 库页 > 其他

#### 4.3 移除 GitHub 登录按钮或实现功能

**现状**：GitHub 按钮显示但点击提示 "coming soon"。

**建议**：要么实现 GitHub OAuth（Firebase 支持），要么直接移除该按钮，避免负面体验。

### 🟡 P1 — 影响转化和留存，近期需要

#### 4.4 增加使用量可视化（Quota Indicator）

**位置**：侧边栏顶部或顶部栏

**设计**：
```
┌─────────────────────────┐
│  Free Plan              │
│  ████████░░ 8/10 music  │
│  ██████░░░░ 12/20 images│
│  [Upgrade →]            │

```

**作用**：
- 用户随时知道剩余额度

- 提升付费转化率

#### 4.5 Dashboard 接入真实数据

**现状**：全假数据，无实际内容。

**建议**：
- 接入 `/api/songs` 和 `/api/images` 获取用户作品

## 7. 无障碍性审查

### 7.1 现状评估

| 维度 | 评分 | 说明 |
|------|------|------|
| 语义化 HTML | ⭐⭐⭐⭐ | 正确使用 `<nav>`, `<main>`, `<header>` |
| 键盘导航 | ⭐⭐⭐ | 基本可用，但模态框焦点管理待优化 |
| 颜色对比度 | ⭐⭐⭐⭐ | 暗色主题对比度良好（白色文字 on 深色背景） |
| ARIA 标签 | ⭐⭐ | 部分图标按钮缺少 aria-label |
| 焦点指示器 | ⭐⭐ | 缺少自定义 focus-visible 样式 |
| 减少动画 | ⭐⭐⭐⭐ | 已有 `prefers-reduced-motion` 媒体查询 |

### 7.2 建议

1. 为所有图标按钮增加 `aria-label`
2. 模态框打开时锁定焦点（Focus Trap）
3. 增加 `:focus-visible` 自定义样式
