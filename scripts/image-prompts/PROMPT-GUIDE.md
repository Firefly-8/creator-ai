# 生图 Prompt 书写指南

## 公式

```
风格 + 视角 + 主体 + 背景 + 细节 + 光影 + 质量词
```

---

## 各维度详解

### 1. 风格 (Style)
定义整体视觉语言和美学方向。

| 类别 | 关键词 |
|------|--------|
| 极简 | minimalist, clean, simple, flat |
| 3D | 3D render, isometric, clay render, glassmorphism |
| 插画 | vector illustration, flat design, hand-drawn |
| 科技 | futuristic, cyberpunk, sci-fi, tech |
| 商务 | corporate, professional, modern business |
| 艺术 | abstract, watercolor, oil painting, gradient |
| 暗黑 | dark mode, gothic, noir |
| 复古 | retro, vintage, 80s synthwave |

### 2. 视角 (Perspective)
定义观察角度和构图方式。

| 类别 | 关键词 |
|------|--------|
| 正面 | front view, straight-on, eye-level |
| 俯视 | top-down, bird's eye view, overhead |
| 仰视 | low angle, worm's eye view |
| 侧面 | side profile, lateral view |
| 等距 | isometric view, 45-degree angle |
| 特写 | close-up, macro, extreme close-up |
| 广角 | wide angle, panoramic |
| 环绕 | 360 view, turntable |

### 3. 主体 (Subject)
核心要表现的对象。

- 具体描述：A majestic lion, a sleek smartphone, a music note
- 数量：single, pair, group of three
- 状态：floating, standing, exploding, transforming
- 材质：metallic, glass, liquid, holographic, matte

### 4. 背景 (Background)
环境衬托。

| 类型 | 关键词 |
|------|--------|
| 透明 | transparent background, PNG cutout |
| 纯色 | solid color background, solid black/white |
| 渐变 | gradient background, color gradient |
| 环境 | studio setting, outdoor, urban, nature |
| 抽象 | abstract background, bokeh, geometric |
| 无缝 | seamless pattern, repeating |
| 场景 | on a desk, in a room, floating in space |

### 5. 细节 (Details)
精细度和纹理。

- **纹理**: smooth, textured, grainy, brushed metal, carbon fiber
- **边缘**: sharp edges, soft edges, rounded corners
- **装饰**: engraved, embossed, foil stamping, enamel
- **元素**: with sparkles, with particles, with glowing lines
- **精度**: highly detailed, intricate, precise, clean lines

### 6. 光影 (Lighting)
照明效果。

| 类型 | 关键词 |
|------|--------|
| 柔和 | soft lighting, diffused light |
| 戏剧 | dramatic lighting, chiaroscuro |
| 霓虹 | neon glow, bioluminescent |
| 背光 | backlit, rim lighting, silhouette |
| 体积光 | volumetric lighting, god rays |
| 环境光 | ambient light, studio lighting |
| 反射 | reflections, caustics, refractions |
| 高光 | highlights, specular highlights |

### 7. 质量词 (Quality)
画质增强词。

```
8K, ultra HD, high resolution, sharp focus, 
professional, masterpiece, best quality, 
highly detailed, crisp, clean, 
award-winning, studio quality, pristine
```

## 实用模板

### Logo / 图标
```
[风格] logo mark of [主体], [视角], [背景], 
[细节], [光影], [质量词]

示例：
Minimalist geometric logo mark of an abstract letter C, 
front view, transparent background, clean sharp edges, 
soft gradient lighting, 8K ultra HD professional
```

### 产品配图
```
[风格] render of [主体], [视角], [背景], 
[细节], [光影], [质量词]

示例：
3D glassmorphism render of a floating music player interface, 
isometric view, dark gradient background with soft bokeh, 
highly detailed with frosted glass texture and neon accent lighting, 
volumetric light rays, 8K studio quality
```

### Blog 配图 / Hero
```
[风格] illustration of [主体], [视角], [背景], 
[细节], [光影], [质量词]

示例：
Modern flat vector illustration of a creative workspace with AI elements, 
wide angle view, soft gradient purple-to-dark background, 
geometric shapes and subtle grid pattern, 
ambient lighting with soft glows, ultra HD clean professional
```

### 图标 / 贴纸
```
[风格] icon of [主体], [视角], [背景], 
[细节], [光影], [质量词]

示例：
Cute clay render icon of a rocket launching, 
front view, solid pastel purple background, 
smooth matte texture with subtle shadows, 
soft studio lighting, 8K crisp high resolution
```

## 快速组合表

需要快速生成时，从每列各选一个组合：

| 风格 | 视角 | 主体 | 背景 | 细节 | 光影 | 质量 |
|------|------|------|------|------|------|------|
| minimalist | front view | abstract mark | transparent | clean edges | soft glow | 8K |
| 3D render | isometric | product mockup | gradient | glass texture | volumetric | ultra HD |
| flat vector | wide angle | scene illustration | solid color | geometric | ambient | sharp |
| dark futuristic | low angle | tech element | dark nebula | neon traces | rim light | masterpiece |
| clay render | close-up | cute character | pastel | smooth matte | studio | crisp |

---

## 注意事项

1. **越具体越好** — "purple gradient" 比 "colorful" 更有效
2. **质量词放最后** — 作为画面收尾增强
3. **避免矛盾** — 不要同时写 minimalist 和 highly ornate
4. **透明背景** — 必须明确写 "transparent background"
5. **Logo 类** — 建议加上 "vector style" 或 "flat design"
